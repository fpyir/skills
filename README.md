# Skills

Some skills I've made for coding agents.

## Available skills

| Skill | Description |
| --- | --- |
| [Field Guide Explainer](field-guide-explainer/) | Create self-contained HTML explainers with forest-green panels, editorial typography, annotated examples, and interactive diagrams. Includes a starter page, a design-system reference, and a complete IFC example. |
| [Manage PR Stack](manage-pr-stack/) | Coordinate stacked pull requests across GitHub, Jira, and local Git using durable stack records, a Python CLI, and a rebase helper. |

## Usage

Copy the complete directory for the skill you want into your coding agent's skills directory. Keep its supporting assets, references, and scripts alongside `SKILL.md`.

For example, invoke Field Guide Explainer with:

```text
Use $field-guide-explainer to explain how database indexes work
as a self-contained visual HTML guide.
```

Each skill's `SKILL.md` describes when to use it and how it works.
